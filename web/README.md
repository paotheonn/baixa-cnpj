# Interface web

Interface local em Next.js e shadcn/ui para o pipeline RF CNPJ.

A API e o comando de linha ficam na raiz do repositório. Instalação, variáveis de ambiente e uso estão no [README principal](../README.md).

```bash
npm install
npm run dev
```

O endereço padrão é `http://localhost:3000`. A URL da API local pode ser definida em `web/.env.local`, a partir de `web/.env.example`.
